Install Pop Out (temporary manual method)

This extension is awaiting review on the Microsoft Edge Add-ons store. Until that's approved, here's how to install it directly.

Download popout-extension.zip

Setup steps

  1. Download the ZIP above.
  2. Unzip it — you should end up with a folder (not just the .zip file) containing files like manifest.json.
  3. Open Edge and go to edge://extensions.
  4. Turn on Developer mode (top-right toggle).
  5. Click Load unpacked.
  6. Select the unzipped folder (the one containing manifest.json, not the zip itself).
  7. Done — the extension is active. It only runs on chaturbate.com pages.

Edge will show a small "unpacked extensions" notice — that's normal for this manual install method and goes away once the extension is available through the official store.
